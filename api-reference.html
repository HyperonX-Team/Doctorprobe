API reference

Base URL /api. All errors use the envelope {"detail": "message"}. Interactive docs are served at /docs (Swagger UI). Endpoints marked auth require Authorization: Bearer <token>; those marked device require X-API-Key when DEVICE_API_KEY is configured.

Login rate limiting

Login is limited to AUTH_LOGIN_MAX_ATTEMPTS attempts per IP within AUTH_LOGIN_WINDOW_SECONDS; exceeding it returns 429.

Checkups

MethodPathAuthBody / QueryReturns
POST/api/checkupsauth—CheckupCreated (201)
GET/api/checkups/{id}auth—CheckupResponse (decrypted)
DELETE/api/checkups/{id}auth—{"detail"}
POST/api/checkups/{id}/shareauth—ShareResponse
GET/api/checkups/{id}/exportauth—PDF (application/pdf)
  • POST /api/checkups analyses the user's latest device burst; returns 409 when no reading exists.
  • Ownership is enforced: another user's checkup returns 403.
  • Sharing awards TOKEN_REWARD once; a second share returns 409.

Trends

MethodPathAuthBody / QueryReturns
GET/api/trendsauth?window_days= (1–365, default 30)per-marker series, stats, alerts

Returns checkup_count, alert_count, and a markers map keyed by analyte with points (oldest → newest), stats (mean/std/min/max/latest), and alerts. See Trends & alerts.
