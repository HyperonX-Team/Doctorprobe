Frontend overview

A React 18 + TypeScript (strict) + Vite 5 + Tailwind 3.4 single-page app. Every page has explicit loading, empty, and error states, and non-2xx responses surface the backend's detail message.

Structure

src/
  api/         typed fetch client + endpoint constants (no secrets)
  types/       mirrors the backend Pydantic schemas exactly
  context/     UserProvider — bearer-token session
  hooks/       useUser, useCheckup, useDeviceStatus (polling)
  components/  layout shell, ChatBubble, ReportTable, Toast, dialogs…
  pages/       Welcome, Login, Home, Checkup, Report, History,
               Trends, Vault, Calibration, Settings
  utils/       formatters, error messages
tests/         welcome, login, checkup, report, trends, calibration,
               toast, confirm-dialog, useUser

The pages

RoutePurpose
/welcomeRegistration: email + password + profile.
/loginEmail + password sign-in.
/Home: token balance, latest checkup, device status.
/checkupRun an analysis from the latest device reading.
/report/:checkupIdChat-style report, quality banner, share + PDF export.
/historyAll checkups, newest first, with delete.
/trendsPer-marker SVG charts, stats, and alerts over 30/90/365 days.
/vaultArchive view + JSON export with encryption fingerprint.
/calibrationSample coverage per analyte, model status, CSV export.
/settingsEmail, device id, sharing toggle, change password, delete account.

Session handling

  1. Sign in — login(token, user) stores the token in localStorage (doctordrobe_token) and the profile in context.
  2. Every request — the API client attaches Authorization: Bearer <token> automatically.
  3. Startup — UserProvider re-hydrates via GET /api/auth/me; a 401 clears the token and signs out.
  4. Logout — best-effort server-side revocation, then local state cleared.

The router guards routes: unauthenticated users are redirected to /welcome; signed-in users are redirected away from the auth pages.

API client

src/api/client.ts is a typed fetch wrapper: JSON parsing, the {"detail"} error envelope surfaced as ApiError(status, message), blob fetches for the PDF/CSV exports, and the bearer header. Endpoint paths live in endpoints.ts; the base URL comes from VITE_API_BASE_URL (localhost:8000 in dev, /api behind Nginx in production).

Quality gates

npm run dev       # Vite dev server (port 5173)
npm run build     # tsc -b typecheck + production build
npm test          # Vitest + React Testing Library (33 tests)
npm run lint      # ESLint, zero warnings allowed

Tests use mocked fetch and URL-aware response shapes — no network calls escape the test environment. The session token is stubbed via localStorage and the context's login.

No UI library

Charts and tables are hand-rolled (SVG polyline charts, semantic HTML tables) — zero runtime dependencies beyond React and the router.
