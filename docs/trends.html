Trends & alerts

A single reading is a snapshot; a sequence of checkups is a signal. Trends turns the time series you're already collecting into something you can act on - with explainable, deterministic alerts.

Why longitudinal matters

The biggest gap between a home gadget and a health tool is context. Cortisol at 0.4 µg/dL means little in isolation; a cortisol line that has climbed every morning for a week means something. Trends make the data self-referential: the user's own history becomes the baseline.

The API

GET /api/trends?window_days=30 (auth required, 1-365 days):

{
  "window_days": 30,
  "checkup_count": 12,
  "alert_count": 2,
  "markers": {
    "glucose": {
      "name": "Salivary Glucose", "unit": "mg/dL",
      "ref_low": 0.5, "ref_high": 7.0,
      "points": [
        {"date": "2026-08-01T08:00:00Z", "value": 2.1, "state": "normal", "confidence": 0.9},
        {"date": "2026-08-05T08:00:00Z", "value": 2.4, "state": "normal", "confidence": 0.9}
      ],
      "stats": {"count": 12, "mean": 2.3, "std": 0.4, "min": 1.9, "max": 3.1, "latest": 2.8},
      "alerts": [
        {"type": "rising_trend", "severity": "warning",
         "message": "Salivary Glucose has risen over the last 3 checkups (2.10 → 2.80 mg/dL). Worth keeping an eye on."}
      ]
    }
  }
}

The service decrypts the user's own checkups server-side and returns only aggregates - never encrypted payloads. Series are oldest → newest, so the UI can draw them directly.

The alert rules

All alerts are deterministic and conservative - a heads-up to look closer, never a diagnosis:

TypeRuleSeverity
rising_trendThe last 3 values each rose.warning
falling_trendThe last 3 values each fell.info
deviation_from_baselineLatest value is > 2 standard deviations from the mean of the user's earlier readings.warning
repeated_out_of_range≥ 2 of the last 3 readings fell outside the reference range.warning
new_out_of_rangeThe latest reading went out of range after in-range readings.info

Alerts only fire with at least 3 checkups in the window, so a couple of noisy points never trigger anything.

The Trends page

  • Window switcher - 30 / 90 / 365 days; the charts refetch per window.
  • Per-marker SVG line charts - dependency-free, with the reference range drawn as a shaded band and points coloured by state (low / normal / high).
  • Stats line - latest, mean, and the state chips per point.
  • Alert cards - the explainable message for each fired rule.

Roadmap

  • Push notifications for out-of-range readings and missed checkups.
  • Time-of-day analysis (cortisol is morning-sensitive).
  • Per-marker quality-weighted series that down-weight poor captures.
