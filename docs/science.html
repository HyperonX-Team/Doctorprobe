Analysis science

How a $4 colour sensor reading a strip of paper becomes five biomarker concentrations - and why the pipeline is honest about when it can't.

1. The strip is colorimetric chemistry

Saliva test strips carry reagent pads. Each pad reacts with one analyte and develops a coloured chromogen whose intensity follows the Beer-Lambert law: 

A = -log10(R / R0)          # A: absorbance
                            # R: pad reflectance (what the sensor sees)
                            # R0: blank (unstained) reflectance

concentration = A * slope   # within the linear region of the calibration curve

The firmware normalizes every raw channel against the sensor's clear channel, so the values in the API payload are lighting-independent reflectance proxies in 0..255. A darker pad = stronger reaction = higher concentration.

2. The ill-posed problem

Three RGB channels cannot uniquely determine four Beer-Lambert concentrations (pH is a ratio and stays on its own closed form). That is an ill-posed inverse problem. The naive approach - a fixed RGB→panel mapping - quietly overfits. Doctordrobe does three things instead:

  • Bursts, not snapshots. A burst of snapshots of the same strip is deconvolved as one over-determined linear system - replicate measurements average out ADC/optical noise and add equations beyond the three channels.
  • Physics-constrained NNLS. The solution is a non-negative least-squares fit of the Beer-Lambert extinction model, regularized (Tikhonov) toward a prior.
  • Honest confidences. Every analyte carries an identifiability score derived from the least-squares covariance, so the report can say "this marker could not be resolved" instead of printing a confident-but-arbitrary number.

3. The spectral solver

app/services/spectral.py implements the reconstruction:

Design matrix
Beer-Lambert extinction coefficients per channel per analyte (the physics).
Prior
SaliNet's prediction when the artifact is present, else the closed-form Beer-Lambert calibration - steadies the ill-conditioned directions only; the physics fit drives the data.
Outputs
Concentrations, per-analyte standard errors, and analysis metadata: condition_number, rank, reconstruction_residual, n_measurements.

The report's analysis block exposes all of this, so the numbers are auditable: which solver, which prior, how many snapshots, how ill-posed.

4. SaliNet - the machine-learning prior

SaliNet is a small Random Forest (one forest per analyte) that inverts rgb_r, rgb_g, rgb_b, temperature_c, humidity_pct into a concentration prior:

  • Forward model → data. scripts/generate_synthetic_data.py simulates Beer-Lambert chemistry + pad cross-talk + ADC noise and generates the training CSV.
  • Training. scripts/train_model.py fits the forests (150 trees, depth 11, seed 42) and writes salinet.joblib + a salinet.json manifest with per-analyte R²/MAE and provenance.
  • Real data priority. When an analyte has ≥ 15 real calibration samples, the trainer uses them instead of synthetic data - the calibration workflow.
  • Fallback. If the artifact is missing, the analyzer uses the closed-form Beer-Lambert estimate as the prior and reports prior_source: "beer-lambert".

Why a Random Forest? It is small, fast, needs no feature scaling, exposes feature importances (a studyable model), and is deterministic for a fixed seed.

5. Profile adjustments

Deterministic physiology adjustments are applied after reconstruction:

  • Older age and higher BMI nudge glucose and CRP up (metabolic physiology).
  • Activity level adjusts secretory IgA (exercise bolsters mucosal immunity; overtraining at athlete level blunts it).
  • Temperature enters the Beer-Lambert fit via enzyme-kinetics coefficients; high ambient humidity dilutes soluble markers (sIgA).

6. Risk scoring

Each out-of-range marker contributes a fixed weight - but only when its spectral identifiability clears the confidence gate. A marker the measurement could not resolve never inflates the risk label. Thresholds: ≥ 0.45 → high, ≥ 0.2 → medium, else low.

Deterministic by design

The same snapshot + profile always produce the same report - no random sampling, no simulated readings. Reproducibility is what makes longitudinal trends meaningful.
