Doctordrobe

A home-health analyzer you can build, calibrate, and understand. An ESP32 reads saliva test strips with an RGB colour sensor; a FastAPI backend turns the colorimetric chemistry into a five-analyte biomarker panel; a React SPA shows you encrypted reports, trends, and alerts.

This documentation covers every layer - from the parts list to the spectral reconstruction math - with step-by-step tutorials.

Not a medical device

Doctordrobe is an educational home analyzer, not a medical device. The sensor model ships trained on simulated chemistry until you calibrate it with real samples. Confirm any clinically significant finding with a laboratory test and a clinician.
