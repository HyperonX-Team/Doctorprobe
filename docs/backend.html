Backend overview

A FastAPI application with an async SQLAlchemy ORM, Alembic migrations, and a deterministic analysis pipeline. Everything is env-configured and runs in one container.

Stack

  • Python 3.11 · FastAPI 0.111 · Pydantic v2 + pydantic-settings
  • SQLAlchemy 2.0 async - asyncpg (PostgreSQL) / aiosqlite (dev)
  • Alembic migrations · Fernet report encryption · structured JSON logs
  • scikit-learn + joblib for the SaliNet model artifact

Repository layout

backend/
  app/
    main.py            app factory, CORS, exception envelope, /health
    api/routes/        auth, checkups, devices, shares, trends, calibration
    core/              config (env-driven), security, logging
    db/                base, async session
    models/            SQLAlchemy ORM models
    schemas/           Pydantic v2 request/response models
    services/          analyzer, spectral, report, trends, export, calibration_stats
    utils/             crypto, passwords, map_range
  alembic/             migrations
  scripts/             generate_synthetic_data.py, train_model.py
  tests/               pytest + pytest-asyncio (in-memory SQLite)

The service layer

ServiceResponsibility
analyzer.pyDeterministic pipeline: profile adjustments → spectral solve → risk → quality grade.
spectral.pyThe physics-constrained NNLS solver with Tikhonov prior and per-analyte standard errors.
report.pyOrchestrates a checkup: latest burst + baseline → analyze → encrypt → persist.
trends.pyDecrypts a user's checkups into per-marker series, stats, and deterministic alerts.
export.pyBuilds the clinician-facing PDF with quality and trends appendix.
calibration_stats.pyPer-analyte sample coverage vs the retrain threshold + model manifest status.

Testing

72 pytest tests run against an in-memory async SQLite database - no external services required: 

cd backend
python -m pytest -q     # 72 passed

Coverage includes the full auth lifecycle, ownership guards (401/403), trends alert detection, quality grading, PDF export, and calibration stats. CI also runs alembic upgrade head as a migration smoke test.
